### 단계 4. 튜닝 및 전후 비교

Q1~Q10별로 실행계획에서 실제 병목이 확인된 경우에만 최소한으로 튜닝한다.

- 필터를 조인·집계 전에 적용할 수 있는지 확인
- 불필요한 컬럼과 중복 조인 제거
- 주문 단위 선집계로 중복 계산 제거
- 기존 인덱스 사용 여부 확인
- 필요한 경우에만 복합·부분 인덱스 후보 작성
- 변경 후 동일 조건과 동일 데이터에서 다시 측정

### 단계 6. 조인 방식 정리

| 조인 | 적합한 상황 | 특징 | 확인 포인트 |
|---|---|---|---|
| Nested Loop Join | 외부 결과가 작고 내부에 유효한 인덱스가 있을 때 | 외부 행마다 내부 탐색 | 반복 횟수와 인덱스 사용 |
| Hash Join | 동등 조인, 비교적 큰 입력 | 한쪽 해시 테이블 생성 | 메모리, Batch, Hash Cond |
| Merge Join | 양쪽 입력이 조인 키로 정렬됐을 때 | 정렬된 입력을 순차 병합 | Sort 비용과 정렬 인덱스 |

실습 쿼리의 실제 `EXPLAIN` 결과에서 각 조인 사례를 찾고, 없으면 작은 재현 쿼리로 비교한다.
