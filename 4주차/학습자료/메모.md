### 바이트 코드(.pyc)

- PVM 파이썬 실행하면 AST로 컴파일된 pyc파일을 읽을 수 있게됨
- 파이트 코드를 통해 어떻게 하면 메모리, 속도 등 성능 개선이 가능하다

> 코드의
>
> import dis
>
> def add(x,y) :
> return x + y
> dis.dis(add) #바이트 코드 출력

- AST : Abstract Syntax Tree
  - 우리가 작성하는 코드를 컴퓨터가 이해하기 해줌 (컴파일러,인터프리터)
  - 코드의 구조를 명확하게 보여줌ㅡ

### 메모리 관리 전략

- Reference Counting : 객체마다 참조 수 저장, 0이 되면 삭제
- Cyde Detector : 순환 참조 후 수동 해제
- GC 모듈 : gc.collect()
