# Python 종합 실습 2 최종 배포본

## 구성

- `Python_종합실습2_파일IO_예외처리_Pydantic.md`: 프로젝트 생성부터 제출까지 이어지는 전체 교재
- `images/`: 요구사항, 구조도, 환경 설정, 실행 결과 이미지
- `student_project/`: 수강생이 직접 구현하는 TODO 프로젝트
- `complete_project/`: 실행과 자동 검사를 마친 완성 예제

## 실습 시작

1. Markdown 교재를 엽니다.
2. `student_project/`를 별도 작업 폴더로 복사합니다.
3. 가상환경을 생성하고 `python -m pip install -r requirements.txt`를 실행합니다.
4. `practice2.py`의 TODO를 구현합니다.
5. `python practice2.py`와 `python practice2_check.py`를 차례대로 실행합니다.
6. 전체 검사 통과 후 `practice2.py`의 제출용 복사본을 만듭니다.

`input/sales_input.csv`는 제공된 실습 데이터입니다. 내용을 수정하거나 별도로 제출하지 않습니다.
