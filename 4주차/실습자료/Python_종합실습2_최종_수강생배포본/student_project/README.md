# Practice 2 학생용 프로젝트

## 실습 순서

① 가상환경을 생성하고 활성화합니다.

② Pydantic을 설치합니다.

```bash
python -m pip install -r requirements.txt
```

③ `practice2.py`의 `TODO` 부분을 완성합니다.

④ 메인 프로그램을 실행합니다.

```bash
python practice2.py
```

⑤ 자동 검사를 실행합니다.

```bash
python practice2_check.py
```

⑥ `전체 검사를 통과했습니다.`를 확인한 뒤 제출용 복사본을 만듭니다.

제출할 때 `practice2.py`를 직접 이름 변경하지 않습니다. 원본은 자동 검사에 필요합니다.
