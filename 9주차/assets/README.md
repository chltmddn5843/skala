# PartFlow 공정 시각자료

- `PartFlow_공정흐름.png`: 작업지시부터 품질 기록 요약까지 보여주는 생성형 일러스트. 부가 날짜와 소품은 가상 예시.
- `PartFlow_공장배치도_초안.png`: 단일 M1 설비와 LOT 대기·검사 공간의 배치 참고 이미지. 초기 시안으로, 보관에서 소재로 돌아가는 화살표와 LOT-A의 중복 위치 표현은 실제 업무 규칙으로 사용하지 않는다. 해당 수정 생성은 중단되었다.
- `PartFlow_편집용_공정흐름.svg`: 현장 흐름과 MES 정보 흐름을 분리한 벡터 자료. Figma 가져오기용이며 원격 Figma 반영은 도구 호출 한도로 미완료.
- `PartFlow_공정흐름_프롬프트.md`: 최초 일러스트 생성 프롬프트.

현재 자료는 설계 설명용이며 실제 설비 연동이나 동작 앱 구현을 의미하지 않는다.
