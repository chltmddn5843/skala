# PartFlow 서비스 개요

## 서비스 이름

**PartFlow**

부품을 의미하는 `Part`와 작업지시부터 생산·검사까지 이어지는 흐름을 의미하는 `Flow`를 결합한 이름이다.

> 아날로그 설비의 생산 기록을 LOT 중심으로 연결하는 경량 MES

## 서비스 목적과 배경

오래된 제조 설비에는 생산수량과 설비 상태를 MES로 자동 전송하는 PLC·센서 연동이 없을 수 있다. 이 경우 작업자는 생산실적과 이상징후를 종이 작업일보나 구두로 전달하고, 생산관리자와 품질담당자는 서로 다른 기록에서 필요한 내용을 다시 찾아야 한다.

특히 품질검사에서 규격 이탈이 발견되면 다음 내용을 빠르게 확인하기 어렵다.

- 어떤 작업지시로 생산했는가?
- 어느 설비에서 언제 생산했는가?
- 작업자가 생산 중 어떤 이상을 관찰했는가?
- 같은 설비와 시간대에 생산된 다른 LOT은 무엇인가?
- 검사 결과와 아직 확인되지 않은 사항은 무엇인가?

PartFlow는 기존 설비를 교체하거나 직접 제어하지 않는다. 작업자가 PC나 태블릿으로 작업 시작·종료, 생산수량, 이상징후를 입력하면 이를 작업지시와 LOT에 연결한다. 품질담당자는 생산정보, 측정값, 이상기록을 한 화면에서 확인하고 추가로 검사할 관련 LOT을 찾는다.

이번 프로젝트의 목적은 기본 MES의 `작업지시 → LOT 생산실적 → 품질검사 → 이력 조회` 로직을 구현하고, 아날로그 설비 환경에서도 품질 문제를 추적할 수 있는 최소한의 기록 구조를 설계하는 것이다.

## 핵심 가치

### 1. 생산 흐름의 가시성

작업지시의 목표수량, LOT별 생산수량, 검사대기와 검사완료 상태를 하나의 흐름으로 보여준다. 생산관리자는 현재 생산이 어디까지 진행됐는지 빠르게 확인할 수 있다.

### 2. LOT 중심의 품질 추적

품목, 작업지시, 생산설비, 생산시간, 작업자 이상기록, 검사 측정값을 LOT 기준으로 연결한다. 품질담당자는 규격 이탈이 발견된 LOT의 생산 배경을 여러 문서에서 다시 찾지 않아도 된다.

### 3. 품질 확인 범위 탐색

이상 LOT과 같은 품목·설비이며 사용자가 지정한 시간대와 생산시간이 겹치는 LOT을 추가 확인 후보로 제시한다. 후보는 불량 확정 결과가 아니라 품질담당자의 조사 범위를 정하는 근거다.

### 4. 기록 해석 보조

AI가 작업자와 품질담당자의 메모를 `관찰된 사실`, `미확인 사항`, `다음 확인 질문`으로 요약한다. 규격 판정과 관련 LOT 선정은 서버 로직이 처리하며 AI가 품질 합격이나 원인을 결정하지 않는다.

## 주요 기능

| 사용자 | 주요 기능 | 얻는 정보 |
| --- | --- | --- |
| 생산관리자 | 작업지시 생성·조회·종료 | 목표수량, LOT별 생산량, 전체 진행률 |
| 작업자 | 작업 시작, LOT 생산실적 입력, 이상징후 등록 | 현재 작업과 누적 생산량, 등록된 현장 관찰 기록 |
| 품질담당자 | 품질 확인대기 조회, 치수 측정값 등록 | 규격 근거, 제품별 PASS/FAIL, 부적합 수량 |
| 품질담당자 | 관련 LOT 후보 조회 | 같은 품목·설비·조사시간에 해당하는 추가 확인 대상 |
| 품질담당자 | AI 메모 요약 생성 | 관찰 사실, 미확인 사항, 다음 확인 질문 |

## 대표 사용 흐름

`작업지시 생성 → 작업 시작 → LOT 생산실적 등록 → 이상징후 등록 → 품질 확인대기 → 치수검사 → 관련 LOT 조회 → 메모 요약`

예시로 생산관리자가 BR-A 10개 작업지시를 생성하면 작업자는 M1 설비에서 LOT-A 5개와 LOT-B 5개를 생산한다. LOT-A 생산 중 평소와 다른 소음을 관찰해 등록하고, 품질담당자는 구멍 지름 검사에서 5개 중 2개의 규격 이탈을 확인한다. 이후 같은 M1 설비와 조사시간에 해당하는 LOT-B를 추가 확인 후보로 조회한다.

## 프로젝트 범위

이번 버전은 한 공장, 한 생산 공정, 브래킷 품목, LOT당 최종 치수검사 1회를 다룬다. 3D 공장, PLC·센서 자동수집, 실시간 설비 제어, 원자재 추적, 재작업, 출하 기능은 포함하지 않는다.
